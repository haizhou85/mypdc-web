# LaLa个人使用的PAD工具（mypdc-web）

自用的智龙迷城（Puzzle & Dragons）组队 / 伤害减伤计算网页，参考 PDC ダメージ計算 的功能。

基于 [Mapaler/PADDashFormation](https://github.com/Mapaler/PADDashFormation)（智龙急速阵型）。本仓库**只存放我加的功能**，
网站由 GitHub Actions 每天自动拉取上游最新代码和怪物数据（日服、美服、韩服），叠加这些功能后发布到 Cloudflare Pages（https://lalapad.pages.dev/ ）和 GitHub Pages，
所以游戏更新后数据会自动同步。

## 功能

上游已有：组队（单人 / 2人 / 3人）、宠物搜索和筛选、中文技能说明、队伍 HP 与减伤统计、按编号等多种排序。

本仓库新增：

- **默认简体中文界面**（仍可在页面上切换语言）；首页直接打开单人编队页面
- **排序：★自身HP** —— 可选等级（110/120）、是否计入超觉醒、是否激活自力觉醒
- **统一基础HP** —— 假定所有宠物基础 HP 相同，只比较觉醒带来的倍率效果
- **激活条件觉醒** —— 计算 HP/攻击/回复时可选择激活：自力、武装（武器同色，与自力同时勾选时只算一次）、协力、熟成（5/10层）、阴阳加护、部位破坏
- **列表显示搜索结果（默认）** —— 表格列出 HP、攻击、回复、最短CD、觉醒和超觉醒，点表头排序，点行选中宠物；手机上精简为 No./HP/攻击/回复/CD 五列，名称和觉醒放在第二行，不用左右滚动；可切换图标模式（按同样的排序显示）
- **条件一改就自动搜索** —— 去掉了“开始搜索”按钮；屏幕下方随时显示结果数量，点一下跳到结果列表；没有任何条件时显示最新 100 只；编辑窗口标题栏右侧“清空条件”一键清除所有筛选
- **满加蛋 +891** —— 能力值按每项加蛋 297 计算（武器最多 +297），选中宠物时详细信息的加蛋也随之设为 +891，默认 +297
- **精简界面** —— 顶部去掉二维码、我的箱子、数据更新时间按钮，按钮更紧凑，来源声明放在页面最下面，“拖拽时复制”移进展示信息开关列表；去掉帮助/反馈链接、附加显示栏、上游排序下拉框，以及“关闭/清空/分享搜索”按钮
- **★主动技能筛选** —— PDC 式按钮：破吸、解封、各种 buff、HP上限提升、威吓、破防、三种重力、破白盾（可选破坏数 0.5/1/2/3 个，以上/以下/仅）、变敌属性（可选属性）、转己方属性（可选转成的属性或随机）、生成珠子（按颜色，含转珠/洗版/随机产珠/固定位置生成，以及废珠、毒、猛毒、炸弹）、产珠形状、轮盘珠等，可 AND/OR 组合，可限制最短CD、效果持续回合、HP上限倍数下限和伤害上限下限（亿）（如“减伤 ≥ 5 回合”），列表有“持续”列
- **觉醒搜索选项（参考 PDC）** —— “溜技能回合数算作SB”（加速 1 回合 = 1 个 SB 觉醒）、“觉醒赋予算作觉醒”（武器技能赋予的觉醒也参与觉醒搜索）
- **搜索栏整理** —— 类型 AND/OR 放到“类型：”右边、默认 OR，去掉杀觉醒快捷按钮、官方觉醒排序开关和快速开关一栏；所有勾选框统一为开关样式
- **竖版截图** —— 宽屏时“绘制截图”也按竖向排列输出
- **宠物详情精简** —— 不显示经验值、Lv 按钮、消耗、加蛋 ×0；×1/×3 放在三维右侧；技能说明默认去掉图标和 6 格队伍位置标记（条件面板可打开）；手机上技能标题收成一行，单只宠物的信息尽量一屏放下
- **随机技能合并显示** —— 官方数据里只差一项的随机技能（例如“变成火以外的属性”写成随机 4 选 1），共同效果只列一次，不同的部分列成“随机其中一种”；只差变成哪种属性的直接写成一句话
- **添加到主屏幕** —— 手机页面底部提示把网站加到主屏幕当 App 用（安卓可一键安装，iPhone 显示操作步骤），加到主屏幕后全屏打开
- **手机适配** —— 按设备实际宽度显示（上游固定 664px，手机上整页被缩小），文字和按钮按正常大小显示、加大触控区域；编队 6 列等固定宽度区块自动缩放到屏宽；点队伍里已有的宠物直接滚到宠物信息卡片
- **觉醒赋予** —— 编队上方“赋予”开关：按已使用觉醒赋予武器技能的状态计算（武器移除、觉醒赋予本体、自力生效），觉醒统计和 HP 等能力值都会更新；技能筛选里可按“能赋予哪些觉醒”找武器（AND/OR）
- **开技计算** —— 队伍信息下方可以选择要开的盾技能、HP 上限提升技能和变属性技能（只改宠物属性、武器属性不变，按变色后重算武装共鸣、同属性加成和队长技倍率）（列出队员和辅助能用的），选中后徽章旁边的 HP、减伤（和队长技减伤相乘）、等效HP 直接更新并用橙色显示；默认不开技；支持多段进化技能
- **辅助失效开关** —— 上游的“解除辅助”改为“辅助失效”：点一次所有辅助失效、按没有辅助重新计算（按钮变红），再点一次恢复原来的辅助；失效期间保存到队伍库时仍保存原来的辅助
- **📚 队伍库** —— 无需登录，任何人都能把编好的队伍“保存到队伍库”（名称、作者、备注）；队伍库列表可搜索、点开查看，每个队伍有分享链接 `solo.html?team=编号`，队伍库本身的链接是 `solo.html#teams`；打开后可以修改，再保存会存成新的队伍；删除只能通过管理专属链接 `solo.html#teams-admin`（普通页面没有入口），输入管理密码后才能删除。后端是 Cloudflare Worker + D1（`worker/`），由部署流程自动部署，需要仓库 Secrets：`CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`、`ADMIN_KEY`（管理密码）
- **🛡 关卡伤害**（队伍标题右边的按钮）—— 参考 PDC：按“层 → 敌人 → 技能”列出每个技能的伤害、先制，以及封觉醒、封珠、锁珠等提示标签；按当前队伍（HP、队长技/徽章/觉醒/潜觉减伤、开技（面板里可直接选盾和 HP 上限技能，和编队上方同步）、觉醒无效）算出实际承受伤害（绿色扛得住、红色扛不住）和还差几个属性减伤潜觉（1% / 2.5%）；熟成按层数（5F 起、10F 起）自动重新计算队伍 HP，部位破坏数可在面板里选择，每个敌人标题右边显示这一层的队伍 HP
  - 关卡存在服务器上，所有人都能看；用管理密码登录后（管理专属链接）可以新建、编辑、删除，也可以用 JSON 导入
  - 仓库 `dungeons/*.json` 里的关卡会在部署时自动建到服务器上（服务器已有同名关卡时，只有文件里的 data.rev 更大才覆盖）

## 关卡数据

官方接口没有“关卡里有哪些敌人、打多少伤害”的数据，所以关卡需要录入（可以把 PDC 截图发给 Claude 整理成 `dungeons/*.json`，或在网页管理模式里直接编辑）。

## 目录

```
src/
  mypdc-common.js     公共工具、接入上游的队伍刷新
  mypdc-impart.js     觉醒赋予（编队计算开关、赋予觉醒查询）
  mypdc-detail.js     宠物详情：随机技能合并、技能说明图标开关
  mypdc-sort.js       能力值计算（条件觉醒）和排序
  mypdc-list.js       列表显示、主动技能筛选
  mypdc-dungeon.js    关卡伤害（服务器上的关卡库、承受伤害计算、管理员编辑）
  mypdc-skilluse.js   编队开技（盾、HP上限）后的等效HP
  mypdc-teams.js      队伍库（保存、列表、分享、管理删除）
  mypdc.css           样式
  mypdc-mobile.css    手机适配样式
build.sh              合并上游 + 本仓库，生成 site/
worker/               队伍库、关卡库后端（Cloudflare Worker + D1）和部署脚本
dungeons/             要建到服务器上的关卡（JSON）
.github/workflows/    每日自动构建发布
```

## 本地运行

```bash
git clone --depth 1 https://github.com/Mapaler/PADDashFormation.git upstream
./build.sh upstream site
cd site && python3 -m http.server 8000   # 打开 http://localhost:8000/solo.html
```
